KT4 · Chuyển dữ liệu cũ (Google Sheets → Supabase)

Trang này chạy hoàn toàn trong trình duyệt — dữ liệu không gửi đi đâu khi chỉ chuyển đổi & tải CSV. Trình tự: chọn bảng → chọn file xuất từ Google Sheets → xem trước → tải CSV sạch → nạp vào Supabase.

Trước khi xuất từ Google Sheets: nên chạy hàm SUA_MST_MAT_SO_0 một lần. Nếu quên, trang này cũng tự thêm lại số 0 đầu cho MST.

Tải CSV sạch & nạp vào Supabase

Sau đó trên Supabase: Table Editor → chọn bảng tương ứng → Insert → Import data from CSV → chọn file vừa tải. Tiêu đề CSV đã trùng đúng tên cột nên hệ thống tự khớp. Bấm Import là xong.

Hoặc: nạp thẳng vào Supabase (dành cho admin)

Cần đã điền config.js và đăng nhập bằng tài khoản admin. Cách này bỏ qua bước tải/ nạp CSV thủ công.
